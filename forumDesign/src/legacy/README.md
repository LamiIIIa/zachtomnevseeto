# Скрипты старого дизайна

Снимок сделан из администраторских полей тестового форума. Системные рекламные и аналитические скрипты MyBB сюда не входят.

## Inline-код

Имя файла сохраняет исходное место и порядковый номер тега `<script>`.

### HTML верх

- `header-01.js` — ранняя установка выбранной темы;
- `header-03.js` — настройка PR-входа; пароль удалён из проекта;
- `header-05.js`–`header-07.js` — настройка уведомлений;
- `header-08.js` — изображение ссылки в цитате;
- `header-14.js`, `header-15.js` — выделение и копирование кода;
- `header-16.js` — кнопки прокрутки вверх и вниз;
- `header-19.js` — конфигурация масок профиля.

### HTML низ

- `footer-02.js` — подсказки и заголовки элементов;
- `footer-03.js` — случайное всплывающее изображение;
- `footer-04.js` — аватар по умолчанию;
- `footer-05.js` — обработка содержимого сообщений;
- `footer-07.js` — ограничения формы профиля;
- `footer-08.js` — бросок кубиков;
- `footer-09.js`, `footer-11.js`, `footer-12.js` — предпросмотр сообщений;
- `footer-13.js`, `footer-14.js` — параметры URL, ссылки и аватары;
- `footer-17.js` — загрузка новостей;
- `footer-20.js` — диаграмма характеристик.

### Объявление и форма ответа

- `announcement-01.js` — переключатель тем;
- `reply-form-01.js` — стандартный спойлер;
- `reply-form-04.js` — счётчик символов;
- `reply-form-05.js` — кнопка кубиков;
- `reply-form-07.js` — набор стикеров;
- `reply-form-08.js` — дополнительные цвета редактора.

## Внешние зависимости

Файлы из `vendor/` — зафиксированные снимки. Их исходные адреса и позиции перечислены в `external-scripts.json`. Комментарии об авторах и лицензиях сохранены.

Служебные загрузчики уведомлений и автообновления MyBB тоже сохранены для полноты, но при окончательном переносе их лучше оставить внешними: платформа обновляет их независимо от дизайна.

## Безопасный переход

1. Переписать один старый скрипт как модуль в `src/features/`.
2. Подключить модуль через соответствующий `src/pages/*.js` или `src/main.js`.
3. Проверить его на всех затронутых страницах.
4. Только после проверки удалить исходный тег из админки MyBB.

Не импортируйте каталог `legacy` целиком: некоторые файлы требуют глобальные переменные MyBB, зависят от порядка загрузки и используют `document.write`.
