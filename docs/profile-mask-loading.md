# Загрузка масок

Маски и их настройки выполняются отдельной ранней цепочкой на DOMContentLoaded. Они не ждут window.load, готовности оформления или остальных дополнительных плагинов. Порядок: поля профиля, скрипт масок, inline addMask. Общая очередь дожидается этой цепочки, повторное выполнение исключается.

Проверка прав авторов — один асинхронный users.get на неизвестные ID. В памяти страницы сохраняются только полученные авторы; при новой загрузке права запрашиваются заново. Содержимое постов с уже применённой маской пропускается, новые и изменённые посты обрабатываются после pun_post/pun_edit. Ответ для заменённого или удалённого поста не применяется. Ошибка запроса не даёт дополнительных прав.

Личное maskListUser читается только при открытии диалога, асинхронно. Поздний ответ не перезаписывает изменения списка, сделанные после начала чтения. Явные операции записи/удаления сохраняют прежнюю проверку актуального хранилища.

Проверка: node scripts/mask-rendering.test.cjs. Тест удерживает загрузку картинки и готовность оформления, проверяет применение масок, работающий таймер во время запроса, один users.get на несколько постов и повторное использование прав для нового поста. Вход в тему не читает личные маски.
