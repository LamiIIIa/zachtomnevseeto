# Загрузка масок

Маски и их настройки выполняются отдельной ранней цепочкой на DOMContentLoaded. Они не ждут window.load, готовности оформления или остальных дополнительных плагинов. Порядок: поля профиля, скрипт масок, inline addMask. Общая очередь дожидается этой цепочки, повторное выполнение исключается.

Проверка прав авторов — один асинхронный users.get на неизвестные ID. В памяти страницы сохраняются только полученные авторы; при новой загрузке права запрашиваются заново. Содержимое постов с уже применённой маской пропускается, новые и изменённые посты обрабатываются после pun_post/pun_edit. Ответ для заменённого или удалённого поста не применяется. Ошибка запроса не даёт дополнительных прав.

Личное maskListUser читается только при открытии диалога, асинхронно. Поздний ответ не перезаписывает изменения списка, сделанные после начала чтения. Явные операции записи/удаления сохраняют прежнюю проверку актуального хранилища.

Проверка: node scripts/mask-rendering.test.cjs. Тест удерживает загрузку картинки и готовность оформления, проверяет применение масок, работающий таймер во время запроса, один users.get на несколько постов и повторное использование прав для нового поста. Вход в тему не читает личные маски.


## Стабильный первый показ текста

Ранняя очередь также обрабатывает цитаты и ползунок шрифта. До первого показа inline-helper читает FNTsize и создаёт CSS с выбранным размером. Сброс ползунка убирает эту настройку, изменение ползунка обновляет её. Числовые заголовки цитат скрыты до обработки; отступ под аватар резервируется ещё при разборе HTML. Внешний вид готовой цитаты не меняется.

Balsamiq Sans и Nunito Sans используют font-display:optional вместо поздней подмены уже отрисованного шрифта. Кириллические и латинские начертания обычного и курсивного текста предварительно загружаются из локальных файлов форума. При медленной загрузке шрифта браузер сохраняет исходный запасной шрифт до следующего открытия страницы — текст не скрывается целиком.

node scripts/text-layout.test.mjs проверяет сохранённый размер до запуска ползунка, отсутствие сдвига текста и следующего абзаца при ответе API цитат, сброс настройки. Проверки идут на ширинах 390 и 1280px с искусственно задержанными ресурсами.


## Конфликт с форматированием поста

После асинхронного users.get проверяется актуальность узла поста, автора и содержимого самой маски. Изменения цитат, размера текста и прочего оформления не отменяют применение маски. Если во время запроса изменили саму маску, выполняется повторная обработка с уже полученными правами. Для очистки кодов используется актуальное содержимое, а не снимок до запроса.
