# Фоновые изображения карточек

Обычная карточка на компьютере имеет размер `510 × 200 px`. Для экранов высокой
плотности рекомендуется экспортировать файлы `1020 × 400 px`. Последняя
карточка нечётной категории может иметь размер `1040 × 200 px`, поэтому при
`background-size: cover` важную часть изображения лучше оставлять в центре.

У каждой темы есть отдельные переменные для обычного состояния и новых сообщений:

- `--forum-card-image`
- `--forum-card-image-unread`

Отдельные мобильные файлы можно подключить через:

- `--forum-card-image-mobile`
- `--forum-card-image-unread-mobile`
