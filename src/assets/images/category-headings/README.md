# Изображения заголовков категорий

Готовые изображения тем нужно складывать в эту папку. Рекомендуемый размер
экспорта: `2164 × 100 px` для отображения в размере `1082 × 50 px`.

Рекомендуемые имена:

- `shinobi.webp`
- `oto.webp`
- `akatsuki.webp`
- `green.webp`
- `kakashi.webp`

После добавления файла замените `none` в переменной соответствующей темы
`--category-heading-image` на
`url('../../assets/images/category-headings/<имя>.webp')`.

Отдельный мобильный файл можно подключить через переменную
`--category-heading-image-mobile`.
